## コンセプト: デーティング適合性診断エージェント (Dating Compatibility Agent)

マッチングを決定する前に、相手との適合性（相性）を評価・検討できるようにユーザーをサポートするAIエージェント。エージェントはユーザーに代わって決定を下したり、「人間の採点」をしたりするのではなく、共通点や相違点、不足している情報、話し合うべき質問事項を可視化・整理する手助けをします。

### メインフロー

1. ユーザーはおすすめプロフィール一覧を確認し、詳しく知りたい相手を1人選択する。
2. 「相性分析」をクリックし、エージェントとのプライベート分析ルームに入る。
3. エージェントは双方のプロフィール情報と、ユーザーが設定した優先事項を組み合わせて初期分析を行う。
4. 画面の構成要素:
   - エージェントとの対話チャット: 目標、価値観、ニーズ、譲れない条件（ディールブレイカー）を明確にする。
   - 直感的なチェックリスト: 一致している点、追加確認が必要な点、考慮すべき違い。
   - 相性マップ（Compatibility Map）/ チャート: 長期的目標、人生観・価値観、コミュニケーション、ライフスタイル、趣味、現実性、将来設計、譲れない条件。
   - 信頼度 / データ充実度: 情報が不足している段階で断定的な結論を出しているような誤解を防ぐ。
5. エージェントによる提案: 会話のきっかけとなる共通点、次に投げかけるべき質問、デートのアイデア、明確にすべきテーマ。
6. 有望だと感じた場合、ユーザー自身が主体的に「マッチング」または「つながりリクエスト」を送信する。

### 二人がメッセージのやり取りを始めた後

エージェントは、二人の実際のチャット内容を閲覧・盗聴したり、勝手に介入したりすることはありません。

ユーザーは **「検討中プロフィール / 分析履歴 (Profiles I’m Exploring / My Analyses)」** 画面からいつでも分析済みの相手を再度開き、エージェントとの相談を継続したり、やり取りの中で新しく分かった情報を更新したりできます。エージェントはそれに応じてチェックリスト、チャート、留意点、次の質問案をアップデートします。

### プロダクトの提供価値

現在のマッチングアプリの多くは、プロフィールの検索や最初の会話のきっかけを提供してくれますが、「その相手が自分の時間や感情を投資するに値するかどうか」を吟味・評価するサポートは十分にできていません。

エージェントがもたらす価値:

- 写真や自己紹介文、第一印象の直感だけでマッチングすることを防ぐ。
- 共通の価値観や重要な相違点を早い段階で認識できる。
- ありきたりな雑談ではなく、本当に確認すべき質問が分かる。
- 選択肢が多すぎることによる「マッチング疲れ（過負荷）」を軽減する。
- 納得感と根拠を持って主体的にマッチングの判断ができる。

プロダクトのポジショニング:

> デーティングのための意思決定支援コパイロット（Decision-support copilot）: 透明性が高く、目的意識を持った安全な相性探求をサポート。

### 対処すべきリスクと課題

- データの不足や、プロフィールが本人の実像を反映していないことによる誤った分析。
- AIが偽の確信を与えたり、マッチングを強制するようなプレッシャーをかけること。
- 文化、ライフスタイル、ジェンダー、関係性の規範に関するバイアス。
- 個人情報および恋愛・交際に関する極めてセンシティブなデータ。
- 少ない情報からエージェントが勝手な推測や心理的なラベリング（決めつけ）を行うこと。
- 「相性が高い」ことが「安全である」と誤解されること。

設計原則:

- 常にユーザーが意思決定者であること。
- ユーザーが同意・提供した情報のみを使用すること。
- 個人の「良し悪し」を採点しない。あくまでユーザーが設定した優先事項との合致度を評価する。
- 各結論に至った根拠・データを明示すること。
- 分析の信頼度と不足している情報を表示すること。
- 条件や重み付けの調整、分析履歴の非保存・削除を可能にすること。
- 「相性の評価」と「マッチング時の安全性」を明確に区別すること。

### AIハッカソンにおける差別化ポイント

現在、多くのアプリがAIによるプロフィール推薦、マッチングスコア算出、自己紹介文生成、会話のオープナー提案などを提供しています。本コンセプトの独自性は、単なるチャットボットやマッチング提案ではなく、以下にあります:

> AIガイドによる相性探求（AI-guided compatibility exploration）: つながる前に相性をじっくり見極められる、透明でユーザー主導のプライベート分析スペース。

ハッカソンMVPで注力すべき範囲:

```text
プロフィール一覧
→ 相手を選択
→ エージェントによる相性分析
→ チェックリスト ＋ 相性マップ (Compatibility Map)
→ 質問案・オープナーの提案
→ ユーザーによる新情報の追加・更新
→ マッチング、または後で確認するために保存
```

これにより、実用性をしっかり担保しつつ、ハッカソンのスコープを超えてフル機能のマッチングアプリ開発に肥大化することを防ぎます。
